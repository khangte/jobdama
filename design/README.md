# Notion 연결 UI 시안

`notion-connection.html`은 API를 호출하지 않는 독립적인 디자인 검토용 시안이다. 앱 코드는 변경하지 않는다.

브라우저에서 파일을 열고 하단 상태 전환 버튼으로 미연결, 연결 입력, 연결 정보, 해제 확인, 연결 오류를 확인한다. 입력 폼에 공백 없는 임의의 값을 넣으면 연결된 화면을 체험할 수 있다. 실제 토큰을 입력할 필요는 없다.

## 설계 의도

- 미연결은 오류가 아닌 준비 단계로 표현한다. 작은 파란 안내와 연결 버튼만 본문에 배치한다.
- 토큰과 DB 입력은 모달로 모아 공고 목록과 분리한다. 환경변수 이름은 접을 수 있는 도움말로 제공한다.
- 연결 후 상단 상태 버튼에서 채용 지원 관리 DB와 연결 해제를 확인한다.
- 해제 확인에서 새 공고 저장 중단과 기존 Notion 데이터 유지, 재시작 시 환경변수 재적용을 안내한다.
- 토큰 마스킹, 보기 전환, 요청 중 상태, 입력 오류, 연결 오류, 성공 안내를 포함한다.

## 로컬 검증

- Chromium에서 연결 입력 → 연결 정보 → 해제 취소 → 해제 완료 흐름을 검증했다.
- 토큰 표시 전환, 연결 후 입력값 초기화, 연결 오류 표시를 확인했다.
- 1440px 데스크톱과 390px·320px 모바일에서 가로 넘침이 없음을 확인했다.
- `notion-*.png`는 해당 브라우저에서 캡처한 시안 이미지다.

## Penpot 반영 상태

- 사용자 요청에 따라 연결된 `jobdama` 파일의 `Page 1`에 편집 가능한 보드 9개를 추가했다.
- `05`~`09`: 데스크톱 미연결, 연결 입력, 연결 정보, 해제 확인, 연결 오류.
- `10`~`13`: 모바일 연결 입력, 연결 정보, 해제 확인, 미연결.
- 원본 화면 옆에 배치했으며, 새 보드는 텍스트와 도형으로 구성했다. UI를 캡처한 이미지는 넣지 않았다.
- 연결·취소·닫기·해제·연결 유지의 주요 화면 이동 19개를 연결했다. 실제 API 호출은 하지 않는 디자인 프로토타입이다.
- Penpot 렌더링을 확인했고 입력·해제 모달의 텍스트가 컨테이너 안에 있는지 검증했다.
- 파일과 보드 식별자는 `penpot-handoff.json`에 기록했다.

## 연결 설정 변경

- 관심 기업 리스트 DB 입력란, 연결 정보 행, `COMPANY_DATA_SOURCE_ID` 도움말을 로컬 시안과 Penpot에서 제거했다.
- 앱의 연결 API와 설정에는 별도 기업 DB 입력이 이미 제거되어 있어 중복 수정하지 않았다. 기업 DB는 채용 DB의 기업명 relation에서 자동으로 찾는다.
- 변경 후 Chromium 시안 검증과 연결 API·Notion 저장소 테스트 36개가 통과했다. Penpot 입력 모달·연결 정보 렌더링과 텍스트 넘침도 확인했다.
