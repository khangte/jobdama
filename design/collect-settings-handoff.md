# 수집 조건 화면 핸드오프

Task 7의 `/collect/settings` 구현은 [계획서](../docs/superpowers/plans/2026-11-08-collect-settings-web.md)의 Phase 3 화면 결정 사항과 [로컬 시안](collect-settings.html)을 따른다. 시안은 `?state=default|error|saved|broken`으로 기본·입력 오류·저장 완료·설정 파일 오류를 볼 수 있으며 실제 API를 호출하지 않는다.

Penpot 보드 6개와 부품 4세트의 식별자는 [구성 기록](penpot-organization.json)에 있다. `task6/collect-settings` 체크포인트에 화면과 이동 연결을 저장했다.

## 화면·상태

| 보드 | 상태 | 핵심 표시 |

| D04-02 · 수집 조건 / 입력 오류 | 사이트 0개·검색어 31자 | 폼 위 요약과 두 필드 오류 |

`D03-03 · 수집 / 완료`의 `선별 조건`은 설정값 12개를 보여 주고 `조건 바꾸기`를 `/collect/settings`로 연결한다. 설정 화면의 `← 자동 수집`은 `/collect`로 돌아간다. 모바일도 같은 정보 순서와 문구를 쓴다.

## 데이터·상호작용

- `GET /collect/settings`는 `config`, `problem`, `running`, `choices`를 표시한다. 현재 메뉴는 `자동 수집`이며 `aria-current="page"`다.
- 사이트 체크박스는 `sites[]`, 숫자 입력은 `max_per_site`, 검색어는 `keyword`, 선택 상자는 `job`, `region`, `career`, `education`, `employment`, `salary`, `sort`, 여러 줄 입력은 `title_exclude_words`, `body_signal_words`에 대응한다.
- 모든 선택 상자의 첫 항목은 `무관`; 검색어의 빈 값도 무관이다. 선택지와 순서는 계획서의 `CHOICES`·사이트 매핑 표를 따른다.
- `기본값 불러오기`는 폼만 기본값으로 되돌리고 `기본값을 불러왔어요. 저장해야 적용돼요.`를 알린다. `저장`은 `PUT /api/v1/collect/settings` JSON을 호출하고 성공 시 `저장했어요. 다음 수집부터 적용돼요.`를 `role="status"`로 알린다.
- 실행 중 저장은 허용한다. 안내 `지금 수집 중이에요. 저장한 조건은 다음 수집부터 적용돼요.`를 보여 준다.
- 422 입력 오류는 `입력값을 확인하세요.`를 `role="alert"`에 두고 필드마다 서버 문구를 붙인다. 오류 필드에는 `aria-invalid="true"`, 메시지 ID에는 `aria-describedby`를 단다. 예시 오류는 `사이트를 하나 이상 고르세요.`, `검색어는 30자 이내로 입력하세요.`다.
- 403은 `다른 사이트에서 온 요청이라 저장하지 않았어요.`, 500은 `설정을 저장하지 못했어요.`를 표시한다. 손상된 설정 파일은 `설정 파일을 읽지 못해 기본값을 쓰고 있어요. 저장하면 새로 만들어요.`를 경고 배너에 보여 준다.
- 검색 조건은 데스크톱 2열·모바일 1열이다. 모바일의 저장·기본값 버튼은 전체 폭으로 쌓는다. 시안은 1440·390·320px에서 가로 넘침이 없는지 확인한다.

## 시안 범위

로컬 HTML의 버튼은 기본값 복원과 상태 문구만 시뮬레이션한다. API 저장·서버 검증·값 유지·키보드 제출 동작은 Task 7 구현 대상이다. 공고명 단어 17개와 본문 신호 13개는 [시안](collect-settings.html)의 입력값과 계획서 기본값을 따른다.
