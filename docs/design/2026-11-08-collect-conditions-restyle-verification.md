## 발견 사항과 수정 이력

1. **P1 — 카드 구획·데스크톱 열 수 불일치, 수정 완료.** 기존 구현은 전체를 한 카드에 넣고 검색 조건을 4열로 배치했다. 원본은 `찾을 곳`, `검색 조건`, `거르는 단어`를 나누고 검색 조건을 2열로 둔다. 카드 세 개와 카드 밖 저장 동작 줄로 재구성했다. 변경 전 전체 비교와 수정 후 카드별 비교에서 차이 해소를 확인했다.
2. **P2 — 입력 폭·행 간격·안쪽 여백 불일치, 수정 완료.** 원본 좌표를 읽어 데스크톱 검색 카드 1080 × 690px, 입력 폭 500px, 두 열 사이 24px, 행 시작 간격 147px를 맞췄다. 모바일은 검색 카드 350 × 1330px, 입력 폭 310px, 행 시작 간격 156px로 맞췄다. 실제 브라우저 크기와 같은 배율 비교 양쪽에서 확인했다.
3. **P2 — 선택 상자 화살표의 굵기·색 차이, 수정 완료.** 첫 수정 비교에서 네이티브 화살표가 원본보다 진했다. Penpot의 실제 `펼침 · 직무` 도형 (`a23e83c5-8467-8035-8008-e9c111da12a0`)을 20 × 24px PNG로 읽기 전용 내보내기하고 `app/static/collect-select-chevron.png`로 사용했다. 마지막 확대 비교와 HTTP 200·네이티브 키보드 선택으로 확인했다.

최종 비교에 해결되지 않은 P0·P1·P2 시각 결함은 없다. 아래 차이는 기존 동작과 실제 내용을 보존하기 위한 것으로 별도로 판정했다.

## 의도적으로 유지한 차이

- `/collect` 안의 폼이므로 별도 설정 페이지의 돌아가기 링크나 페이지 제목으로 교체하지 않았다. `수집 조건`은 폼 제목이며 저장 후 실행 안내도 남는다.
- 단어 영역은 기존처럼 기본 접힘이다. 원본과 비교할 때만 펼쳤다. 개수 표시와 오류 시 자동 펼침·포커스를 유지하므로 원본 정적 카드에는 없는 요약이 있다.
- 모바일 원본은 일부 도움말이 카드 끝에 붙거나 한 줄 영역에 넘친다. 실제 도움말 전체를 읽을 수 있도록 줄바꿈과 바닥 여백을 유지했다. 이 때문에 찾을 곳 카드는 원본 300px보다 약 24px, 펼친 단어 카드는 원본 390px보다 약 52px 더 높다. 내용은 생략하지 않았다.
- 원본의 단어 예시와 현행 API 기본 단어 목록은 다르다. 시각 일치를 위해 저장 값을 바꾸지 않았다.
